## 💡 Key Concepts Learned

### 1. Array Rotation
- Learned how to rotate an array left by D positions.
- Studied the in-place reversal technique.
- Time: O(n), Auxiliary Space: O(1).

### 2. Two Pointers
- Understood how to move zeroes to the end while preserving non-zero element order.
- Learned how two pointers help merge sorted arrays.

### 3. Mathematical Approach
- Used the sum formula to find a missing number.
- Learned how to reduce unnecessary comparisons.

### 4. Counting Consecutive Elements
- Learned to maintain a current counter and maximum counter.
- Understood when to reset the current counter.

### 5. XOR Operator
- Learned that `a ^ a = 0` and `a ^ 0 = a`.
- Understood how XOR identifies an element appearing only once.

### 6. Nested Loops
- Independently developed the brute-force Two Sum approach.
- Learned to return indices instead of values.
- Understood O(n²) time complexity.
